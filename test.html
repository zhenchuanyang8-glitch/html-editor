📝 HTML可视化编辑器 - 测试文档

新功能说明：
• 容器操作：点击任意元素可选中，支持复制、粘贴、删除（支持Ctrl+C/V、Delete快捷键）
• 表格多选：拖动单元格可多选，批量修改背景色
• 表格调整：拖动单元格边框可调整列宽和行高

欢迎使用HTML可视化编辑器！这是一个测试文档，用于验证编辑器的各项功能。

这里可以测试加粗、斜体、下划线和删除线等基础格式。

5. 安装说明

1. 在Chrome中打开 chrome://extensions/

2. 开启"开发者模式"

3. 点击"加载已解压的扩展程序"

4. 选择扩展文件夹

6. 功能快捷键

快捷键 功能
Ctrl + C 复制选中的容器
Ctrl + V 粘贴容器
Delete 删除选中的容器
Esc 取消选择
